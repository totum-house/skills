# totum-blueprint

Blueprint completo do Totum OS.

## Visão geral
Estrutura base do Totum OS com padrões de design, conventions and motor HDS.

## HDS (Legacy)
Marque `hds` como legado dentro da categoria frontend. O motor HDS foi incorporado ao totum-blueprint como parte de sua história, mas funcionalidades são mantidas para compatibilidade.

## Quando usar
Como ponto de partida para novos projetos Totum OS, referência de padrões e conventions.
