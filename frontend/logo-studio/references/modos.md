# Operações

| Operação | Intenção | Limite padrão |
| --- | --- | --- |
| Auditar | Entender problemas e oportunidades | Diagnóstico, sem modificar o original |
| Corrigir | Resolver falhas de execução | Preservar conceito, nome e reconhecimento; ajustar apenas defeitos identificados |
| Redesenhar | Reconstruir a forma existente | Manter elementos essenciais acordados e explicar mudanças estruturais |
| Modernizar | Atualizar a linguagem visual | Preservar reconhecimento e legado definidos no briefing |
| Repensar | Explorar outra direção estratégica | Questionar conceito e composição, sem mudar nome ou posicionamento sem autorização |

“Vetorizar” é uma operação técnica complementar, não um sinônimo de modernizar. Um pedido de SVG exige verificar se a imagem é realmente construída por caminhos ou texto editável. Se o usuário pedir preservação integral, não refaça o logo por geração livre: utilize o original, composição e transformações autorizadas.

O logo oficial nunca sai de motor de imagem (regra de 12/11/2026). Foto de cena sem texto pode usar Grok Imagens ou Nano Banana. Peça ou mockup com texto monta no ChatGPT, Images with thinking, com o arquivo do logo anexado.

Se o pedido combinar operações, descreva a sequência. Exemplo: auditoria seguida de correção. Não use modernização como justificativa para trocar símbolo, tipografia, cores e assinatura simultaneamente quando o usuário pediu manutenção da marca.
