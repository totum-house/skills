# Seletores independentes

Estes nomes funcionam como convenções dentro de /logo-studio. Nenhum é um comando nativo do Claude.

| Seletor | Entrega visual | Dados específicos |
| --- | --- | --- |
| /logo_audit | Diagnóstico | Original e contexto |
| /logo_refine | Correção | Defeitos e elementos preservados |
| /logo_redesign | Redesenho | Elementos essenciais |
| /logo_modernize | Modernização | Limite de mudança |
| /logo_rethink | Novos conceitos | Posicionamento e liberdade criativa |
| /logo_system | Versões horizontal, vertical, símbolo e mono pertinentes | Usos e restrições da assinatura |
| /logo_social | Avatar, capa ou assinatura para post | Plataforma, dimensão e texto exatos |
| /logo_stationery | Cartão, papelaria ou assinatura visual de email | Dados fornecidos e tamanho |
| /logo_signage | Fachada ou sinalização visual | Superfície, proporção e distância de leitura |
| /logo_packaging | Aplicação em embalagem | Produto, superfície e medidas disponíveis |
| /logo_mockup | Cena com ativo aprovado | Versão aprovada e contexto |
| /logo_vectorize | Reconstrução vetorial com validação | Fonte, fidelidade e editor/formato desejados |

Cada pedido é independente. Peça só os dados necessários e informe o que será entregue. Aplicações digitais são arte visual; HTML, CSS, programação e integrações precisam de pedido separado. Assinatura de email visual não implica instalar assinatura na conta.

Se o logo ainda estiver em revisão, aplicações opcionais podem ser prévias claramente rotuladas, desde que solicitadas. /logo_mockup final requer logo aprovado. Para /logo_vectorize, compare a reconstrução com a fonte e obtenha aprovação da versão reconstruída antes da entrega final.

Não use mockups para disfarçar problemas do logo. Avalie primeiro o ativo plano. Não invente telefones, endereços, slogans ou nomes em papelaria.
