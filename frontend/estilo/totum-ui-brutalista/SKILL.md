# totum-ui-brutalista

Estilo de interface brutalista para o Totum OS.

## Principípios
- Honestidade material: materiais e componentes expostos sem disfarces
- Grids visíveis: estruturas de grade aparentes intencionalmente
- Tipografia ousada: fontes impactantes, tamanhos grandes
- Superfícies cruas: sem sombras, gradients ou efeitos sutis

## Quando usar
Portfólios, landing pages de impacto, interfaces que querem se destacar propositalmente.
