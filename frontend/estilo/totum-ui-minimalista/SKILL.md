# totum-ui-minimalista

Estilo de interface minimalista para o Totum OS.

## Principípios
- Menos é mais: remover elementos desnecessários
- Espaçamento respirado: usar espaço em branco estrategicamente
- Paleta restraint: cores limitadas, geralmente monocromática ou tons suaves
- Tipografia clara: fontes legíveis, hierarquia clara

## Quando usar
Interfaces que exigem foco e clareza, dashboards, áreas de configuração.
