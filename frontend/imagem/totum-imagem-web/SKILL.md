# totum-imagem-web

Gera imagens otimizadas para interface web do Totum OS.

## Quando usar
Sempre que precisar de elementos visuais para páginas web, dashboards ou interfaces de aplicação Totum.

## Instruções
Use prompts estruturados com referência ao design system Totum para consistência visual.
