# totum-imagem-para-codigo

Gera imagens e ilustrações para acompanhar código e documentação técnica do Totum OS.

## Quando usar
Sempre que precisar de imagens que ilustrem exemplos de código, tutoriais ou documentação técnica.

## Instruções
Use prompts com foco em visualização de código, themes de desenvolvedor e ilustrações técnicas.
