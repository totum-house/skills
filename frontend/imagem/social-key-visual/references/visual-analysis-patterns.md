# Padrões de Análise Visual — Guia de Referência

## Como extrair cor com precisão sem ferramenta de eyedrop

Observar a imagem e identificar:

1. **Cor mais frequente** = background ou base
2. **Cor que aparece em elementos interativos** (botões, destaques, sublinhados) = accent
3. **Cor do texto principal** = quase sempre preta, branca ou cinza
4. **Cor de suporte** = elementos secundários, separadores, ícones

### Família de cores mais comuns em marcas digitais

| Estilo | Característica |
|---|---|
| Tech/SaaS moderno | Azul profundo + branco + accent vibrante |
| Luxury/Premium | Preto ou navy + dourado ou bege + branca |
| Health/Bem-estar | Verde-oliva ou teal + off-white + accent coral |
| Evangélico/Espiritual | Azul royal ou bordô + dourado + branco |
| Agência/Marketing | Vermelho ou laranja + preto + branco |
| Minimalista editorial | Cinza escuro + branco + accent único |

## Como identificar estilo tipográfico sem nome da fonte

| Característica observada | Classificação |
|---|---|
| Serifa pequena, texto em corpo | Serif editorial (Garamond, Crimson, Lora) |
| Serifa grossa, cabeçalho imponente | Serif display (Playfair, Bodoni, Gloock) |
| Sem serifa, neutra e funcional | Sans grotesque (Helvetica, Work Sans) |
| Sem serifa, humanista e amigável | Sans humanista (Outfit, Instrument) |
| Altura de x grande, comprimida | Condensada (Big Shoulders) |
| Traços calígrafos ou orgânicos | Script/Manuscrita |
| Espaçamento uniforme | Monospaced (IBM Plex Mono, Geist Mono) |
| Letras altas, geométricas | Display geométrico (Poiret One, Italiana) |

## Padrões de composição recorrentes em social media

### Minimalismo Premium
- Muito espaço em branco
- Tipografia fina ou média, nunca bold agressivo
- Uma única cor accent usada com parcimônia
- Elementos: poucos, precisos, intencionais

### Editorial Magazine
- Grid rígido mas com quebras deliberadas
- Mistura de escalas (título enorme + corpo pequeno)
- Fotografia ou ilustração forte como âncora
- Tipografia com personalidade, não genérica

### Brutal Expressivo
- Sem margens generosas
- Texto como elemento gráfico dominante
- Cores saturadas em contraste alto
- Formas geométricas cortando o espaço

### Espiritual/Devocional
- Paleta escura com luz emergindo (escuro → dourado/branco)
- Tipografia serifada com peso elegante
- Espaço negativo usado como respiração
- Textura sutil ou gradiente de luz

### Agência/Marketing Direto
- Cor de marca dominante e confiante
- Hierarquia clara: promessa → prova → CTA
- Bold em informação-chave
- Design funcional, não ornamental

## Erros comuns a evitar

1. **Usar mais de 4 cores** em uma única peça → poluição visual
2. **Dois elementos com mesmo peso visual** → sem hierarquia
3. **Texto muito pequeno** em tentativa de caber mais conteúdo → ilegível
4. **Fundo branco + texto preto sem nenhum elemento de personalidade** → peça genérica
5. **Gradiente arco-íris ou muito saturado** sem base no design system → quebra identidade
6. **Centralizar tudo** sem considerar tensão visual → resultado entediante
7. **Usar fonte padrão do sistema** (Arial, Helvetica genérico) quando fontes customizadas estão disponíveis
