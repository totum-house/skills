# design-system-extrator

Extrai e documenta design systems de referência.

## Quando usar
Analisar um design system existente (Figma, implementação, etc.) e gerar documentação estruturada sobre tokens, componentes e padrões.

## Instruções
Extraia cores, tipografia, componentes e documente as regras de uso para consistência visual.
