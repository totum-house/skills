# totum-to-n8n-json

Gera JSON de workflow n8n com mapa de microdecisões para o ecossistema Totum.

## Quando usar
Criar automações no n8n para o ecossistema Totum, com fluxos idempotentes, logging e filas de revisão humana.

## Instruções
Gere o JSON do workflow n8n com nodes, conexões e configurações para o domínio Totum. Inclua mapa de microdecisões para rastreabilidade.
